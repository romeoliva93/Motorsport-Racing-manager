# Immagini dei gruppi tecnici (garage)

Generate in locale con `tools/portraits/parts.py` (SDXL-Turbo, licenza in docs/ASSETS_E_LICENZE.md), 3 varianti
per gruppo, scelta a occhio la più leggibile. Nessun marchio reale.
Limite noto: il modello veloce tende a disegnare la moto intera; per `chassis` e `powertrain` la scelta mostra il
telaio/motore in primo piano ma non isolati. Da sostituire con illustrazioni dedicate se servono più pulite.
