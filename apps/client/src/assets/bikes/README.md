# Foto delle moto per costruttore (archivio)

Generate in locale con `tools/portraits/bikes.py` (SDXL-Turbo, vedi docs/ASSETS_E_LICENZE.md).
**Non sono usate nelle schermate operative**: la moto della squadra è rappresentata dall'illustrazione originale
`design-system/BikeArt.tsx` nella livrea della scuderia (una sola rappresentazione coerente ovunque).
Restano qui come riferimento per una futura galleria/enciclopedia dei costruttori.
`lysander-rookies` e `takaido-lightweight` sono state rigenerate (variante 2) perché il frontale era da moto stradale.
